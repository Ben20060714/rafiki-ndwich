Pour intégrer Google Maps à ton site, suis ces étapes :

1. *Créer une clé API Google Maps*
- Va sur : [console.cloud.google.com](https://console.cloud.google.com/)
- Crée un projet → Active l’API "Maps JavaScript API"
- Obtiens ta *clé API*

2. *Ajoute le script Google Maps dans ton HTML*

```html
<script async defer
  src="https://maps.googleapis.com/maps/api/js?key=TA_CLE_API&callback=initMap">
</script>
```

(Remplace `TA_CLE_API` par ta vraie clé)
